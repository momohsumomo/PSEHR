# 北極星自主電子病歷系統

開源的門診系統。下載後用空的資料庫跑起來，不包含任何診所的病歷、安全模組或藥價整包。

這個倉庫分成兩塊。

## 服務端

除了 `客戶端` 資料夾，其餘都是主機上的服務：門診畫面、資料介面、申報。病歷在主機的 `data/`，不會進 GitHub。

主機第一次雙擊 `啟動-Wundadi門診.bat` 之後，會登記開機啟動。之後這台重新開機、登入 Windows 約 20 秒，服務自己起來，不必再雙擊。不會順便打開看診視窗。

## 客戶端

其他電腦只拷 `客戶端` 這一個資料夾，不要拷整份程式，也不要拷病歷。裡面是這台的開啟門診、讀卡與列印。說明在 `客戶端/安裝說明.txt`。

免安裝的 PDF 檢視器和讀卡軟體安裝檔放在診所自己的那份資料夾，不進 GitHub。

## 從零開始

需要 Python 3.12 與 Node.js。

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
cd frontend
npm install
cd ..
啟動-Wundadi門診.bat
```

畫面是 http://127.0.0.1:3010 ，資料介面是 http://127.0.0.1:5000/docs 。
第一次會在 `data/` 長出這台電腦自己的資料庫。這個資料夾不會進版控。

院所代碼、讀卡機與雲端安全模組要在自己的電腦上設定。程式裡預設的機構代碼只是範例，上線前請改成貴院所的。

## 藥價

GitHub Actions 每月向健保署與食藥署的公開資料拉一次，過關就挂上一個 Release。
整表被清空、筆數過少，或單一藥價暴衝，就不會發佈。

在自己的電腦上雙擊：

```bat
scripts\tools\抓取藥價包.bat
```

抓完後重新啟動門診，新的藥價包會裝進查價。舊病歷仍用就醫當天的價格。
