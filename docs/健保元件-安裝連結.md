# 健保元件安裝連結

轉診上傳只用到下面兩樣已安裝的東西。說明文件不必再裝。

## 要安裝

1. 讀卡機控制軟體 6.0（看診讀卡用，公開下載）
   - 下載頁：https://www.nhi.gov.tw/ch/cp-17933-821b7-2693-1.html
   - 修改歷程：https://www.nhi.gov.tw/ch/lp-3900-1.html
   - 裝「讀卡機控制軟體 6.0 版安裝包」。診所若仍用舊式 DLL 呼叫，同一頁再裝「相容性元件」。
   - Android SDK、虛擬卡元件不必為了轉診上傳另外裝。
   - 6.0 另需 Windows 10 22H2 以上，以及 .NET Runtime 6 與 ASP.NET Core Runtime 6：https://dotnet.microsoft.com/zh-tw/download/dotnet/6.0

2. 醫療資料傳輸共通介面 API（轉診 XML 上傳用，只有 VPN 下載專區）
   - 先登入：https://medvpn.nhi.gov.tw/
   - 左側「下載專區」，服務項目選「醫療資料傳輸共通介面 API」。
   - 簡易版用 3.0 或較新；UI 版用 2.3 或較新。兩種擇一，診所已有哪種就用哪種。
   - 轉診開立的作業種類是 10。這個安裝檔沒有公開直連，連結打不開是因為要先登入 VPN。

## 不用安裝，只是文件

- 電子轉診格式總頁（XML、API 說明、手冊）：https://www.nhi.gov.tw/ch/cp-7947-bb4de-2943-1.html
- 轉診服務說明：https://www.nhi.gov.tw/ch/cp-5155-df1cd-2943-1.html
- 登入後的醫事人員溝通平台下載專區：https://medvpn.nhi.gov.tw/iwse0000/IWSE0030S02.aspx?bc=IPR
- 登入後的電腦設定下載專區：https://medvpn.nhi.gov.tw/iwse0000/IWSE0030S02.aspx?bc=CMS
- 本專案已有一份：電子轉診平台說明

## 更新

- 共通介面的作業說明停在 2020-09-28，要求的版本仍是簡易版 3.0 以上、UI 版 2.3 以上。這個元件沒有公開版本頁，不要做自動更新，也不要登入 VPN 去輪詢。
- 會改版的是讀卡機控制軟體 6.0。有新版時看修改歷程那一頁即可。不要自動安裝。
- 轉診 XML 欄位說明會改（本機這份到 2025-08-05）。那是文件，不是要重裝的程式。
