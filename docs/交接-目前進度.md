# 交接：目前進度（開新對話必讀）

產品對外名稱是**北極星自主電子病歷系統**。公開 GitHub 是 `PSEHR`。程式內部仍有 Wundadi 名稱，不要整庫改名。病歷庫在 `data/shadow.db`，禁止推上 GitHub。

原則以 `docs/專案憲章-原則與方向.md` 為準。下面是已經定過、不要推翻的行為。

## 主機

- 只有主機雙擊 `啟動-Wundadi門診.bat` / `重啟全部-Wundadi門診.bat`。服務在背景，不留命令視窗。
- 其他電腦雙擊 `連到主機.bat`，只開主機的 `:3010`，本機只跑列印代理。
- 說明：`docs/主機與工作站.md`。
- 讀卡軟體 6.0 與診所金鑰不進 GitHub。紅燈能開的就開、能下載的公開工具就下載；VPN 不代登。

## 身分、掛號費、押金

- 身分類別的 `reg_fee` 是**掛費優待**（從院所掛號費往下減，最低 0）。`copay` 是 0/1：1 代表部分負擔優待（櫃檯不收，申報的部分負擔仍是 50）。
- 身分優待和年齡優待（學生、滿 70 歲）只減一次，取比較大的那個。兩邊都是減 100 時，掛號費是 200 減 100，等於 100，不會再減成 0。
- 院所現況：掛號 200、自費掛號 400、押金 500。身分 A 的押金欄是 500、優待 200、部分負擔優待。
- 病歷「押金金額」跟著身分表。實際按押金掛號收的是院所押金，不是舊的病歷餘額。
- 不要再跑一次身分優待遷移（`id_fee_discount_v1`），也不要再跑家護回補。

## 掛號與問診

- 預約報到只對**同一時段**。下午的預約，早上來不拿來報到；早上另掛，下午那筆留著，稍後在掛號作業刪。
- 報到後沿用原號，清掉預約標記，接著就是一般掛號（讀卡，或沒卡就押金／自費）。
- 自助掛號遇到當日預約：顯示「當日已有預約，請直接跟櫃台報到」，不取號。已掛過號要帶號碼。
- 開啟掛號右上角「指定健保卡」把這台唯一的讀卡機指定給讀卡軟體。沒指定就不會讀卡。這一步不讀卡片。指定後，這台之後的健保卡讀取與簽章都連這一台。
- 候診預問診在本機。民國 110 年以後的 7 碼生日要等打完才查。大廳開的是另外一個視窗。
- 同日就診存檔後先關確認頁，再以中間提示約兩秒。
- 大廳刪病歷：完全沒有看診紀錄才允許。有看診就拒絕。病歷與 Media 仍然禁止 DELETE。
- 大廳「工具／對齊照片檔名」把圖庫裡有、資料庫還沒記下的檔名補進去。不刪照片，也不把圖檔本體寫進病歷。
- 刪掉掛號以後，下一筆不要再看到上一筆的主述、病名、處置。那是這台電腦畫面上的暫存，不是資料庫把刪掉的病歷救回來。
- 健保局取號回 3201，是這張卡超過有效期限。3213 才是就醫可用次數為零。這兩種會先請健保局更新這張卡，更新成功再取一次號。更新失敗就停，不會改成 B000。
- 打開門診或掛號時，同時打開讀卡軟體 6.0 和上傳轉診用的 5.1.7。5.1.7 要先確認 `C:\NHI\BIN` 的讀卡機屏蔽，沒有屏蔽就不啟動。門診視窗都關掉之後，兩支一起關。下次打開再一起開。右上角「重啟讀卡軟體」只重開 6.0，「重啟上傳轉診資料專用控制程式(與讀卡無關)」只重開 5.1.7。這兩顆和「重新整理讀卡機」、「指定健保卡」的通知，做下一個動作就收掉。
- 打開一筆看診，歷史清單每次都向資料庫重撈。刪掉的那筆不會留在下一筆的主述、病名、處置。

## 列印方向

- 簡式和押金單：預覽寬 210、長 93。方向選直向時，送印前轉 90 度，印表機收到 93×210 直向。這段已經印對，不要再改轉向、不要把寬高對調、不要用縮放做邊界。規則在 `.cursor/rules/print-feed-locked.mdc`。
- 只有自費要進位：自費額無條件進到下一個十元（808 變成 810，1880 仍是 1880），然後實收等於這個自費加上掛號費、部分負擔、押金。這三個不進位，總額也不進位。已經有自費數字就進那個數字，不要另用藥品單價算出另一個自費。
- 左邊藥名欄寬度固定，多出來的字直接切掉，不換行把那一列撐高。讓出來的寬度給部位。右邊藥名和服用方法也是一行固定高度，多的字直接切掉。
- 按下列印就把這張單交給這台電腦的列印工具，畫面可以先離開。工具在背景印完，不跟著網頁一起取消。這台要關掉門診視窗再雙擊開啟門診，列印工具才會換成會立刻收下的那一版。

## 看診

- 找人先看格式再查一個欄位。純數字是病歷號，不對身分證。中間有點或斜線是生日，102.1.1、102.01.01、102.01.1、102.1.01 同一天。0 開頭 9 到 11 碼是電話。字母加數字是身分證。其他是姓名開頭。
- 看完存檔右側候診名單不含預約。標「預」的人不出現。診療清單仍看得到預約。
- 收據的藥師印人事姓名。畫面上看到的名字，印出來也是那個名字。
- 調閱結果清單選定一筆後按 Enter 進入病歷。
- 調閱結果一出來就依姓名開頭的筆畫排。點左欄任一標頭改依那個欄位排，再點一次順序反過來。補是補卡。
- 左側收據的卡號印當天看診號。
- 藥品主檔有「提醒病患內容」，一格最多二十個字。簡式那個「藥單內容及門診收據列印警語」勾了才印：有字的藥印藥名加這一句，空白的藥跳過。不印適應症、不印藥帶主訴，也不印「主檔未記載」。
- 家護日期空白就是沒有收案，畫面不放 82.01.17。有日期才顯示。病人資料按修改可以改，存的是這個人家護計畫的開始日期。
- 病人主檔欠款有數字而且不是 0，這個人掛號後，診療作業清單和病歷上的姓名用紅色。0 和空白不變色。這筆欠款跟單次看診的費用欠款分開。
- 藥品顯示名用醫聖 INDEX＝Y 那一列。同一快碼若還有未採用的列，不要拿來蓋掉名稱。
- 自費的「自」和註記「[」要跟著處方存檔，存完再開還在。
- 總量單位用藥品主檔的 UNIT，例如 tu、B、次、#、CC。用法檔大小寫是不同列：大寫 QD、TID/PC 這類 ISTOTAL 1 或 2，總量是數量乘次數乘天數；小寫 qd、bid 的 ISTOTAL 0，畫面上的數量就是總量。ISTOTAL 3（例如 KI 的 tid/pc）不乘次數，總量顯示數量加單位。
- 處置沒有填用法時，存檔留白，不自動寫「依醫囑」。
- 部位視窗上面那格可以自己打。下面搜尋按 Enter 也會把打的字加進去。清除把上面已打和已選的部位清掉。備勾選的列，部位確定後勾就消失。
- 主述只補 ICD-9 比對到的 ICD-10 更精確的那一段（例如沒寫到的左右、深度、原因，或病名比 ICD-10 更細）。同一種病不再整句補進主述。
- 費用統計的自費看診只看案件是 9X 或自。部代空白是一般門診。有開自費藥不把這次看診改成自費。從大廳進去的條件畫面，字是原本的 1.6 倍，寬度加到看得到全部條件。統計出來的報表字是原本的兩倍，掛號簿那張紙的高度是原本的三倍。
- 藥品資料的劑型用醫聖 DRUGTYPE 的清單，也可以自己打。存檔先保留這筆原來的欄位，再寫這次改的內容。顏色外觀、雲端查詢類別、當月最大用量、有效日、警告日會一起存。
- 選中的病名和處置用淺綠色底，字維持深色。
- 數量、用法、天數、途徑選中後直接打字就能改。
- 主訴為了省紙仍印成一行。原來的換行用一個 " 標在斷開的地方。
- 診斷 ICD-9、病名、ICD-10 分開打。打在哪一欄，字就留在那一欄。
- 病名搜尋視窗點一下只選取並看細分，點兩下或按寫入才帶入。搜尋把字拆開比對，順序可以不同，例如 wound finger 找得到 open wound of finger。
- 看診右側就診紀錄列表的字縮小到八成、列矮一點。主述、病名、處置的字大小不變。三區之間只留一條黑線。歷史處置不換行，塞不下的字直接切掉。
- 自費案件畫面顯示「自」。資料裡仍存 9X，月申報才會略過。
- 看診時案件跟月申報同一套，對齊這家醫聖：健保給藥滿 7 天就是 04，口服有天數就用口服最長，否則用其他健保藥最長，自費列不算。病名不必在公告慢性病清單。病名主檔有特定治療代號、不滿 7 天也是 04。切開排膿、冷凍、電燒、換藥（51020C、51022C、51006C、51004C、51009C、51010C、51011C、51017C、53016C）是 09，滿 7 天也一樣。這家 Sc.ini 急性加慢性不改 09。交付調劑的一般案件仍是 09。
- 刪掉的藥存檔時改成取消，重新整理不會再出現。病歷不 DELETE。
- F3 改掛號費、部分負擔、押金後，候診清單的總計立刻重算。自費仍只用看診存檔那一筆，總計不進位。
- F9 存檔頁醫師和藥師都是選單，可以在這裡改。
- 藥名和處置搜尋打下一個字就要更新。拆字、不限順序只用於病名。
- 診療和掛號的滾輪，一格只換一位病人。
- 另一台已經讀卡存檔後，這台在清單上點一下、滾一下，或從病歷回到清單，黃圈就會出現。之前清單比對沒把「已寫入」算進去，所以勾在、圈要整頁重進才看得到。
- F2 找人清單有「修改資料」，等於選定後按 F5。關掉修改資料回到剛才的搜尋結果，不會直接回診療。ESC、取消或右上角關掉之後，這位病人不再綁在 F5。下一筆 F5 用清單上選的那位。
- 診療清單的年齡顯示幾歲.幾個月，例如 46 歲 6 個月寫成 46.06。不顯示天。
- 診間是 1、2 這種號碼，畫面上寫 1診。以前把科別寫進診間的，都當成 1診。進診療先選診間，只看該診間的病人。人事資料的診間欄位存這個號碼。掛號的科別仍是皮膚科。
- 按住 Ctrl 再滾輪是調網頁大小。只有滾輪才換病人。
- 看診或就診紀錄存檔，最後一次存的藥和病名才是畫面上和申報讀到的內容。拿掉的列標成取消，不刪除。
- 診療按 Esc 跳出時，後面改成大廳。再按 Enter 用同一個門檻回到診療。看完一筆按 Esc 回到清單時，自動選下一位。
- 進診療的日期、時段、科別、診間、藥師確定後，Enter 可以直接進去。

## 申報、轉診、代檢、補卡

- 處方標記「交」或「轉」就是交付檢驗。看診存檔後，這次只要有這兩種，就另外開一張 A4 橫式「交付檢驗處方箋」。簡式收據仍是 210×93，轉向規則不要動。
- 代檢機構代號在院所設定。申報時交／轉／材的醫令寫 p2=4、p3=4、點數 0、p24=這個代號。數量 0 寫 0，其他都留一位小數（1 寫成 1.0）。藥品 p5 留兩位小數；沒算出每次量時用數量填，不要把次數乘回去。
- 補卡：這次就醫識別碼仍是 d60。原先那組在 `actualTreatId`，而且補卡註記是 2、3、4 才申報 d61。沒有原先那組就不寫 d61。押金退押向健保局用補卡取號（afterCheck 2），每日上傳的補卡註記是 2，上傳日是退押那天。月申報的就醫日仍是原本看診日。空白才從醫聖押金檔補，不覆蓋已有的值。
- 轉出單用病歷號加開單日，對上當天唯一一筆掛號後才寫入就診。申報 d18=Y、d55=轉往院所。轉入（接受轉診且有原院所）寫 d16=1、d17。沒有轉入就不寫 d17。診療畫面存檔只寫進轉診名單，不上傳。大廳電子轉診頁的「上傳這一筆」才送出，走這台雲端 SAM，跟 6.0 佔著的讀卡機分開。還沒送出的轉診，退掛時一併刪。轉出上傳未滿一小時，可以送刪除開立。回復在當天退掛，可以送刪除回復。其他情況不刪轉診紀錄，有這種紀錄的掛號也不能刪。下載每天 07:10 抓昨天到今天的轉出與轉入清單，約十分鐘後取回對齊；頁上「現在下載」是額外再做一次。對齊不拿來決定能不能刪。
- 免部分負擔代號（003–006、901–904、906–915）另寫 d43，數字是基本部分負擔加藥品部分負擔。d40 仍是實收。
- 不要寫 d59。特定治療代號：掛號的 `caseNoE1`（家庭醫師計畫，值是 G8）先寫 d4，病名主檔 SPECIAL 再依序寫 d5、d6。d13 的 P 不是格式規定的註記，不要自己補。
- 主診斷搜尋「刀、knife、跌倒、車禍」時，先列出已有可申報主碼的項目，外因碼不單獨當選項。沒有 ICD-10 的自訂詞不進可選清單。存檔不因外因碼或星號次診斷停住：可申報的受傷碼放主診斷，醫師選的碼移到次診斷，病名文字維持醫師打的。這份申報碼表沒有 T14.1、T14.0，未明示部位用 T14.90。申報組檔同樣把主診斷換成可申報碼，不改病歷庫。外因碼放在次診斷只提醒，檔案仍會帶出去。不因為外因碼改案件分類，也不要求地點碼、活動碼成套。
- 每日上傳：讀卡軟體 6.0 的就醫序號 W001～W999 是正常上傳，安全模組和健保卡號要寫進檔。A000、B000 這類異常代碼仍是異常上傳，這兩欄留空。畫面上的案件 04、09 不寫進這份檔，就醫類別仍是 01。門診醫療費用在組檔時計算，不另存在看診紀錄：每個人用當天的第一階診察費（未滿 4 歲、75 歲以上用該年齡的點數），加上健保藥與處置點數和給藥天數對應的藥事服務費，再減這筆部分負擔。月結的合理量級距仍只在月申報。兩筆看診若寫到同一秒，組檔時把後面那筆的秒數加一，醫令時間一起改。不改看診裡存的時間。同一秒整批送出時，健保署會直接斷線。一天筆數多、檔案大的時候，從主機一次送整天也會被斷線，畫面會停在 0%。改成每次最多 20 筆，兩批中間隔一秒再送。同一秒連送兩批，健保署回同一時間重覆上傳。處方簽章在診療存檔、勾選寫入醫令時向健保卡取得，存進該筆看診，上傳時寫進醫令 D11。藥品、診療、特材要有這欄。沒寫卡的舊看診補不到。

## 費用統計明細

- 總計維持一天一列。明細下載對齊 `費用統計格式` 的欄位：存檔是固定寬度文字（含身分證與後面的收費欄，沒有資料的收費人員／方式留白），轉 Excel 是逗號欄（日期到醫師，含卡優、藥優、自費）。
- 那個資料夾是診所明細，已列入 `.gitignore`，不要提交。

- 不把 KAN-24 知識庫 UI 改掉。
- 修改稽核仍關閉，正式上線才用 `scripts/tools/正式上線-啟用修改稽核.bat`。

## 安裝與更新

- 拿到別台電腦：拷一個 安裝北極星.bat 雙擊。下一步選服務端或客戶端，再選資料夾，從 GitHub 下載。這份要先在 GitHub 上，單檔下載才找得到安裝步驟；同一個資料夾裡已經有 scripts\setup_wizard.ps1 時，直接用旁邊那份。
- 服務端接著雙擊 安裝-主機必要工具.bat，再雙擊啟動。客戶端雙擊 開啟門診。讀卡安裝檔和 PDF 不在 GitHub，下載不會刪掉資料夾裡已經有的那兩樣。
- 大廳右下「更新」分兩條。藥價：這台主機自己向健保署、食藥署抓整份，檢查過再裝進查價，不用重開，不改病歷結構。這個月沒抓成或檔案被擋下，大廳那一列會寫出來。軟體：只安裝 program- 開頭的更新檔（雙擊 scripts/tools/發布軟體更新檔.bat 才會生一份）。只換程式，不蓋 data/。啟動時補欄位：舊列沒有的欄位補空白或預設，不整庫取代。有 .git 的開發資料夾拒絕蓋檔。
