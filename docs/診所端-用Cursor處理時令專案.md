# 診所端：用 Cursor 處理時令專案

## 為什麼要裝 Cursor

健保**常用主幹**（看診、藥價、月申報）由 Wundadi 產品維護。  
**時不時出現的計畫／收案／特殊上傳**（例如家醫群組收案）通常是：

- 官方只有公文 + 格式說明 + **VPN 網頁**（常無穩定 API）
- 每次欄位與條件都可能不同
- 適不適合收案、有沒有重複 → 人在網頁看一眼就懂；程式自動化反而是惡夢

因此標準產品**不提供**「貼上公文 → 一鍵收案保證過關」。  
院所（或資訊人員）用 **Cursor 開啟本專案**，讓 AI 讀這次公文、對本機資料找人、依格式組檔，再**自行到 VPN 網頁上傳測試**。

## 一鍵開啟

雙擊專案根目錄：

`開啟-用Cursor問本專案.bat`

會用 Cursor 打開**本資料夾**（規則與程式碼都在），之後有問題直接在對話裡問即可。

尚未安裝 Cursor：<https://cursor.com>

## 建議怎麼問（範例）

1. 附上本次公文或格式 PDF／說明文字。  
2. 「請依公文摘要收案條件，並用本機影子庫／API 幫我列出可能符合的病人（先給我確認）。」  
3. 「依附件格式說明產生上傳用檔；我不需要你自動登 VPN。」  
4. 上傳後若網頁顯示重複或錯誤，把畫面文字貼回來再改檔。

## 產品會做／不會做

| 會 | 不會 |
|----|------|
| 資料在診所、可查可匯出 | 代你讀懂所有計畫並保證指標 |
| 月申報等主幹模組 | 每個新公告做一個永久內建按鈕 |
| 給 Cursor／人用的本機資料與組檔協助 | 自動操作健保 VPN 網頁直到「收成功」 |

## 與資料權一致

專案條件與是否上傳由**診所**負責；系統與 AI 是工具。  
只想「分錢、廠商全包、院所什麼都不知道」→ 非本產品服務對象。
