# 文件索引（權威順序）

給人與 Agent：先看誰、什麼時候看誰。細節以被指向的檔案為準，本索引不重複抄行為條款。

## 權威順序（衝突時由上到下）

1. `docs/專案憲章-原則與方向.md` — 產品原則、A/B/C、禁止事項  
2. `docs/交接-目前進度.md` — 近期已定行為（掛號、列印、讀卡、LOOK…）  
3. `.cursor/rules/*.mdc` — Cursor Agent 強制規則（與憲章同步維護）  
4. 主題說明（下表）  
5. 程式碼  

根目錄 `AGENTS.md` 是跨專案 Agent 的入口摘要；不取代憲章。

## 過時／勿當現況

| 路徑 | 說明 |
|------|------|
| `CURSOR_PROJECT_HANDOVER.md` | 舊交接；埠號與 API 過時；含診所範例資料。改讀 `AGENTS.md` |
| 根目錄大量 PDF／截圖／論質小工具副本 | 診所現場或參考資料，不是模組定義來源 |

## 維護約定

- 改產品行為 → 先改憲章或「交接」，再改碼。  
- 新模組或新強制約束 → 更新 `docs/模組地圖.md` 與本索引；必要時加 `.cursor/rules/`。  
- 不要再長出第二份「完整交接」複製憲章全文。
