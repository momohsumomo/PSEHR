# 模組地圖

路徑含義與責任邊界。實作細節以程式為準；行為鎖定見 `docs/交接-目前進度.md`。

---

## 倉庫頂層

| 路徑 | 角色 |
|------|------|
| `src/` | 主機後端（FastAPI、影子庫、申報、藥價 Spoke） |
| `frontend/` | 門診 UI（Vite/React）；建置後由主機 :3010 提供 |
| `客戶端/` | **工作站專用**可攜資料夾：開啟門診、desk agent、Sumatra、讀卡輔助。整包拷到別台，不拷病歷 |
| `hub/` | 藥價／參考資料 Pack 發布管線（開放資料 → 檢查 → Pack） |
| `tests/` | `unittest`；`PYTHONPATH` = 倉庫根 |
| `docs/` | 原則與主題說明 |
| `scripts/` | 安裝、重啟、工具 bat／ps1；`scripts/tools/` 維運；`scripts/_peek_*` 多為一次性探測，非產品 |
| `config/` | 設定樣板 |
| `data/` | 執行期資料（`shadow.db`、logs、look…）；**gitignore；禁止推 GitHub** |
| `.cursor/rules/` | Agent 強制規則 |
| `AGENTS.md` | 跨 Agent 入口 |

診所現場可能還有根目錄的讀卡安裝包、論質／轉診小工具、PDF 規格書：視為**現場附檔**，不是核心模組。

HTTP 表面。進入點：`src/api/main.py`（中介層帶機器 ID／PIN 稽核脈絡）。

| `condition.py` | 診斷 |
| `medication_request.py` | 處方 |
| `observation.py` | 觀察／檢驗類 |
| `media.py` | FHIR Media；LOOK 相片資料夾 API（`look-sync`、`look-file`） |
| `outpatient.py` | 門診工作台聚合 |
| `nhi.py` | 健保讀卡／取號等橋接 |
| `claims.py` | 月申報 API |
| `ic_upload.py` | 每日 IC 上傳相關 |
| `referral.py` | 電子轉診 |
| `quality_lab.py` | 論質檢驗 |
| `kiosk.py` | 自助掛號／問診 |
| `desk.py` | 工作站回報（印表機、讀卡、VPN） |
| `clinic_settings.py` | 院所參數 |
| `staff.py` | 人事 |
| `packages.py` | Spoke Pack 進站 |
| `maintenance.py` | 維運（含更新；**Agent 禁止對正式主機亂打更新**） |
| `address_book.py` | 地址／路名 |
| `certificate.py` | 證明類 |
| `same_day.py` | 同日相關 |
| `auth.py` / `sandbox.py` | 驗證／沙盒切換 |
| `allergy_intolerance.py` | 過敏 |

瀏覽器呼叫多半前綴 `/api`（見 `frontend/src/config/sandbox.ts` 的 `API_BASE`）。Swagger：`http://主機:5000/docs`。

### `src/infrastructure/`

| 檔／概念 | 職責 |
|----------|------|
| `sqlite_shadow_store.py` | Local-First 影子庫：資源 JSON + 索引表、稽核、LOOK 檔名表、掛號清單等。**核心持久化** |
| sync worker 等 | 背景同步／佇列（與雲端方向相關時讀此區） |

### `src/core/`

領域邏輯（非 HTTP）。重要子集：

| 區域 | 代表檔 | 職責 |
|------|--------|------|
| LOOK 相片 | `look_images.py` | `data/look`（或 `WUNDADI_LOOK_DIR`／舊 `Z:\SC\IMG`）樹狀病歷號資料夾；對齊、改日期、退休檔 |
| 藥價 | `drug_price_refresh.py`, `drug_pack_fetch.py` | 主機抓開放資料、組 Pack |
| 健保橋 | `nhi_*.py`, `nhi_cshis6_client.py` | 讀卡 6.0、驗證、映射 |
| 掛號／看診 | `encounter_queue.py`, `register_guard.py`, `intake_form.py` | 佇列、防呆、問診 |
| 轉診／論質 | `referral_*.py`, `quality_lab*.py` | 桌面工具與收件 |
| 列印 | `local_print*.py` | 與 desk 列印契約 |
| 地址 | `tw_address.py`, `tw_roads.json.gz` | 3+3 路名 |
| 更新 | `app_update.py`, `github_release.py` | `program-` 更新進站（診所大廳觸發） |
| 醫聖匯入 | `yisheng_register_fields.py`, `care_online_import.py`… | 匯入前讀 `docs/醫聖匯入注意.md` |

### `src/claims/`

**申報組檔唯一出口。** 門診 XML、案件規則、每日上傳輔助、與醫聖對照規則。接手先讀 `docs/申報接手說明.md`。

| 代表 | 職責 |
|------|------|
| `engine.py` / `xml_export*.py` | 組檔與匯出 |
| `case_rules.py` / `yisheng_rules.py` | 案件／對醫聖 |
| `ic_daily_upload.py` / `ic_upload_send.py` | 每日上傳路徑 |
| `nopay_*` / `deposit_refund.py` | 欠款／押金相關檢查 |

### `src/spoke/`

主機上的 Pack 消費端：藥價查詢、Pack 儲存與 hydration。查價給開藥寫入當日快照。

### `src/app/`

啟動組裝（例如 `bootstrap` 取得 store／repository）。

### `src/adapters/`

對外系統適配（若存在具體 adapter，改碼前先讀該檔說明字串）。

## LOOK 相片

- 磁碟樹：病歷號六碼拆成 `aa/bb/cc/`，檔名 `〔六碼〕〔2 碼 base36〕.JPG`。  
- 程式：`src/core/look_images.py` + `media.py` 的 look-* 路由。  
- UI：`PatientLookDialog.tsx`。  
- 「對齊照片檔名」：補 `look_file` 表，不刪圖、不把圖字節寫進病歷。增量對齊依**各病歷資料夾自己的** mtime（勿信上層目錄清單的延遲時間）。  
- 診所另有匯照片 GUI（例如掛號一台的 `clinic-image-categorize-master`）；匯完應呼叫主機 `POST /api/fhir/Media/look-sync`，不要再跑舊醫聖 `img32`。

## 測試與發佈（開發機）

```bat
set PYTHONPATH=<repo根>
.venv\Scripts\python.exe -m unittest discover -s tests -q
cd frontend && npx tsc --noEmit -p . && npx vite build
```

發佈診所程式：`git push` 後 `gh release create program-YYYY.MM.DD.N --repo momohsumomo/PSEHR --target <sha> …`。  
**不要**代替診所按大廳更新。
