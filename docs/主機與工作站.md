# 主機與工作站

病歷只在**主機**。其他電腦用瀏覽器連主機，自己只負責本機列印。不要在工作站再雙擊「啟動門診」，否則會變成另一套空資料庫。

## 主機

1. 第一次：雙擊 `安裝-主機必要工具.bat`（會用 winget 補 Python、Node，建立 `.venv`，並在登入時自動把服務藏到背景）。
2. 平常：雙擊 `啟動-Wundadi門診.bat`。API `0.0.0.0:5000`、畫面 `0.0.0.0:3010`，記錄在 `data/logs/`，沒有命令視窗可關。
3. 改過程式要吃進去：雙擊 `重啟全部-Wundadi門診.bat`。
4. 其他電腦開 `http://主機IP:3010`。私用網路防火牆規則名稱是 `PSEHR-3010`、`PSEHR-5000`；沒有系統管理員權限時規則可能加不上，要手動允許。

## 工作站

1. 同一份程式（git pull），雙擊 `安裝-工作站.bat`，輸入主機 IP。
2. 之後雙擊 `連到主機.bat`。它只打開主機畫面，並在這台電腦背景跑列印代理 `127.0.0.1:5310`。
3. 工作站不放病歷資料庫，也不要跑主機那個啟動檔。

## 大廳紅燈

點紅燈會做能自動做的事：

| 燈 | 點了之後 |
|----|----------|
| 讀卡機 | 主機上若已安裝 6.0，就啟動或重啟主控台 |
| PDF 未裝 | 下載 SumatraPDF 到 `%LOCALAPPDATA%\Wundadi\print` |
| PDF 未起 | 用 `psehr://` 請這台電腦把列印代理打開（要先跑過安裝，登錄過這個協定） |
| 印表機 | 只說明離線，不會假裝修好硬體 |
| VPN | 只提醒人工登入。系統不代登健保 VPN |
| 資料 | 顯示後端連不上。主機服務沒開就回主機雙擊啟動 |

## 讀卡軟體 6.0 與診所金鑰

乾淨電腦的正確起點不是把工具塞進 GitHub。

- **程式本體**放 GitHub（公開 repo `PSEHR`）。病歷庫 `data/`、費用統計範例、讀卡安裝檔、SAM／金鑰都不要推上去。
- **Python、Node、SumatraPDF** 是一般軟體，安裝腳本或紅燈會用 winget／官網下載，不必把安裝檔提交進 repo。
- **健保讀卡軟體 6.0** 是健保署的程式，裝在**有讀卡機的那一台**（目前是主機）。用健保專網下載「健保資訊網服務系統 6.0」。沒裝時紅燈會說明，程式不會自己從不明網址抓。
- **診所認證金鑰、SAM、醫事機構卡** 是健保署發給這家診所的，裝完軟體還要插卡、做一次初始化。不能放進程式、不能從 GitHub 下載，也不能靠「裝了就搞定」。
