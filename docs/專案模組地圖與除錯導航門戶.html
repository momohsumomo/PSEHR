🚪讀卡與掛號模組

沙盒 3

負責與物理健保卡讀卡機（PCSC 通訊協定）連線，並銜接虛擬健保卡 API / 掛號進場註冊流程。

核心程式碼檔案路徑

  • 🐍 utils/nhi_reader.py 📋
  • 🐍 src/api/routers/patient.py 📋
  • 🐍 src/api/routers/nhi.py 📋

❌ 卡片讀不到 / 連線超時？

1. 執行 python utils/nhi_reader.py pcsc 檢測硬體驅動。
2. 確認健保卡控制軟體 6.0 於背景 Port 5066 正常運作。
3. 檢查後端 src/api/routers/nhi.py 串接格式。

💊藥品與處方管理

沙盒 2 / 1

負責處理當次就醫的開藥處方、健保申報碼對照、RxNorm 以及藥物與患者病歷的過敏 CDSS 防撞機制。

核心程式碼檔案路徑

  • 🐍 src/api/routers/medication_request.py 📋
  • ⚛️ frontend/src/pages/DrugCatalogPage.tsx 📋
  • ⚛️ widgets/widgets/CurrentRxWidget.tsx 📋

❌ 藥物過敏警告未彈出 / 找不到藥？

1. 檢查後端 allergy_intolerance.py 的過敏檢索匹配邏輯。
2. 檢查前端 CurrentRxWidget.tsx 是否在處方變更時觸發防撞 API。

👤病人資料與預診

沙盒 1 / 2

患者自訴預診填寫頁面、病人基本資料整合、歷次看診 SOAP 病歷摘要與生命徵象拉取。

核心程式碼檔案路徑

  • ⚛️ frontend/src/pages/PatientPreVisitPage.tsx 📋
  • 🐍 src/api/routers/outpatient.py 📋
  • ⚛️ widgets/widgets/ChiefComplaintWidget.tsx 📋

❌ 雙擊排隊名單無法載入病歷？

1. 排查 outpatient.py 的 /workspace/{encounterId} 是否噴 500。
2. 確認 SQLite 中的 Encounter 與 Patient 的 ID 關聯沒有損毀。

💻UI/UX診間工作台

沙盒 1

負責皮膚科醫生雙欄看診工作台的配置驅動排版、各類看板組件渲染，以及診間快速鍵監聽。

核心程式碼檔案路徑

  • ⚛️ frontend/src/pages/ClinicOutpatientPage.tsx 📋
  • ⚙️ frontend/src/config/ui-config.json 📋

❌ 元件版面崩壞 / 快捷鍵失效？

1. 檢查 ui-config.json 是否是合法的 JSON。
2. 確認 Widget 元件最外層是否保留了 w-full h-full min-h-0。
3. 至 ClinicOutpatientPage.tsx 搜尋快速鍵監聽器。

🗄️雙層SQLite資料庫

基礎建設

系統的儲存底座。實作雙層快取機制：一層完整 FHIR JSON (resource_cache) ＋另一層供快速查詢的 SQL 索引貼紙表。

核心程式碼檔案路徑

  • 🐍 src/infrastructure/sqlite_shadow_store.py 📋
  • 💾 data/shadow.db 📋
  • 🐍 src/infrastructure/sync_worker.py 📋

❌ 存入資料後用 SQL 查不到？

1. 後端寫入時是否同步更新了對應的快取貼紙表（如 _update_patient_index）。
2. 呼叫 GET /sandbox/dual-layer/{type}/{id} 比對雙層落庫一致性。

📸皮膚病灶影像模組

沙盒 2 / 1

提供皮膚科的核心價值：影像記錄。管理病灶縮圖、時間軸、放大對照以及 Base64 照片落庫關聯機制。

核心程式碼檔案路徑

  • 🐍 src/api/routers/media.py 📋
  • ⚛️ widgets/widgets/LesionPhotosWidget.tsx 📋

❌ 照片上傳後無法顯示 / 空白？

1. 檢查 media.py 是否收到正確的 Base64 格式，並確認存入 DB。
2. 檢查前端 LesionPhotosWidget.tsx 是否能正確轉換 Base64 URL 渲染。
