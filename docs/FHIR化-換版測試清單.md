# 禮拜三換版測試清單

轉換跑完、服務啟動後，診所照這張表一項一項做。每項打勾或寫「不對」加一句看到什麼。任何一項「不對」又當天修不好，就還原備份、裝回舊版（見 `docs/FHIR化-最終格式.md`「換版當天」）。

測試用一位測試病人（不是真病人）做新增、修改；看舊資料時只看、不改。

## A. Agent 先做（不用診所動手）

- [ ] 轉換報告：每一步「index unchanged」或只出現事先說明過的變動。
- [ ] `fhir_gap_report.py`：所有類型 0 缺口。
- [ ] 對照錄製（`fhir_baseline.py diff`）：月申報 XML、IC 每日上傳、轉診 XML、論質、報表全部 IDENTICAL；其餘差異逐條說明。
- [ ] 啟動紀錄沒有 `NotConvertedError`。

## B. 掛號、候診、看診

- [ ] 叫出一位老病人：基本資料、電話、地址、身分別跟換版前一樣。
- [ ] 測試病人掛號：候診清單出現、號碼對、狀態能改（候診、看診中、完成）。
- [ ] 看診畫面：主訴、病名、處方、用法、天數、部位、自費註記都存得進去，重開還在。
- [ ] 舊病歷：挑三位常客，最近三次看診的主訴、病名、處方、單價跟換版前一樣。
- [ ] 退掛：測試病人退掛後候診清單消失，病名、處方標成取消，沒有被刪掉。

## C. 費用、讀卡、收據

- [ ] 測試病人結帳：掛號費、部分負擔、藥品部分負擔金額對。
- [ ] 讀卡（在這台讀卡機）：讀得到卡、寫得回卡。
- [ ] 簡式收據、押金單列印：方向、位置、金額跟換版前一樣。
- [ ] 還單、退押：做一筆，現金簿當日金額對；舊的還單在現金簿還看得到。

## D. 文件與轉診

- [ ] 診斷證明：舊的打得開、內容一樣；測試病人新開一張，字號接續、列印正常。
- [ ] 轉診單：清單筆數跟換版前一樣；新開一張、存檔、重開還在；刪掉一張草稿後清單少一筆。
- [ ] 論質檢驗：清單筆數一樣；能存、能匯出。

## E. 照片

- [ ] LOOK 照片：挑兩位病人，照片張數、日期跟換版前一樣，點得開。
- [ ] 新拍一張到測試病人：出現在清單；改日期後重開還是新日期。
- [ ] 病灶照片：舊的看得到。

## F. 申報與報表

- [ ] 這個月的月申報預覽：件數、點數跟換版前一樣（Agent 會先比對 XML）。
- [ ] 每日 IC 上傳清單：今天以前的資料筆數一樣。
- [ ] 現金簿、月報表：上個月的總額一樣。

## G. 人員與設定

- [ ] 人員清單：人數、名字、診間一樣；PIN 登入正常。
- [ ] 院所資料：醫事機構代號、名稱、電話正確。

## 結論

- [ ] 全部打勾 → 上線。
- [ ] 有「不對」→ 記下哪項，決定當天修或還原。
