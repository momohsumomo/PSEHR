【沙盒1】前端 UI（Mock only，不連後端）
  目錄：frontend/
  資料：frontend/src/mocks/ 唯一真相
  啟動：cd frontend && npm install && npm run dev
  網址：http://127.0.0.1:5173
  Jira：KAN-8

【沙盒2】後端 API（Swagger only，不連前端）
  初始化：python scripts/init_shadow_db.py
  啟動：雙擊 啟動-Wundadi門診.bat
  或只開後端：scripts\start_api.bat
  或：python -m uvicorn src.api.main:app --reload --host 127.0.0.1 --port 5000
  Swagger：http://127.0.0.1:5000/docs
  （8800/8888 若 WinError 10013：Windows 保留埠 8734-8833，改 5000）
  雙層驗證：GET /sandbox/dual-layer/{Encounter|Condition|MedicationRequest}/{id}
  Jira：KAN-2、KAN-4

【沙盒3】健保讀卡獨立腳本
  主控台探測：python utils/nhi_reader.py health
  PC/SC 診斷：python utils/nhi_reader.py pcsc
  Jira：KAN-7

【Python 虛擬環境】專案目錄內 .venv（勿污染全域 Python）
  建立（僅第一次）：python -m venv .venv
  啟用（PowerShell）：.\.venv\Scripts\Activate.ps1
  啟用（CMD）：.\.venv\Scripts\activate.bat
  安裝依賴：pip install -r requirements.txt
  讀卡硬體診斷（非產品路線）：python card_reader_test.py
  產品讀卡：Phase 4 KAN-7 健保署讀卡機控制軟體 6.0（主控台 :5066 + 業務端 API）
  離開 venv：deactivate
